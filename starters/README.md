# ECO Polyglot Starter Kit

Each language has an independent task-list example in its own directory. The runnable Rust, Go, Python, JavaScript, and TypeScript versions demonstrate add, complete, filter, and progress operations; the SQL version persists tasks in SQLite. The HTML and CSS folders provide accessible and styled task-list pages. The samples are first-party examples covered by the repository's [MIT license](../LICENSE).

| Language | File types | Run it |
|---|---|---|
| Rust | `.rs` | `cd starters/rust` then `cargo run` |
| Go | `.go` | `cd starters/go` then `go run .` |
| Python | `.py` | `python starters/python/main.py` |
| TypeScript | `.ts` | `cd starters/typescript` then `npm install`, `npm start`, or `npm test` |
| JavaScript | `.js` | `cd starters/javascript` then `npm start` or `npm test` |
| SQL | `.sql` | `python starters/sql/run.py` (persistent SQLite, standard library) |
| CSS | `.css` | Open `starters/css/index.html` in a browser |
| HTML | `.html` | Open `starters/html/index.html` in a browser |

The website shows both equal starter-kit shares and source-byte-weighted percentages. Equal shares are a display choice; GitHub's repository language bar measures the actual source-code bytes, including the website app and API. The website's measured shares are generated from first-party code under `src/`, `starters/`, and `api/`.
